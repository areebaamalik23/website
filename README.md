# Lumenfold Studio

Static agency site: `index.html`, `style.css`, `script.js`. Light theme only. Uses Bootstrap 5, Font Awesome and Google Fonts from CDNs; photos come from Unsplash with fallbacks.

## Run in VS Code
1. Open this folder in VS Code and install the **Live Server** extension.
2. Right-click `index.html` and choose **Open with Live Server**.

## Before launch
- Replace the placeholder email and location in the Contact section and footer.
- The contact form validates in the browser but has no backend, so it sends nothing. Connect a form service to make it live.
- Portfolio projects are concepts and the statistics are illustrative; replace them with real work and figures when available.
- Confirm the Unsplash photo URLs load, or swap in your own images.
